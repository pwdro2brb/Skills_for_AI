# Changelog

## 1.0.1 — 2026-11-25

- Light mode is now the explicit default. Being invoked by name, or the word
  "prove" in a standard exercise, no longer counts as a reason to build a
  ledger; only the task's own uncertainty or stakes, or an explicit request for
  a ledger, report or audit, do. Prompted by a first informal comparison in
  which the skill ran full investigations on two simple problems.
- `agents/openai.yaml`: the default prompt no longer asks for competing
  hypotheses and a computed state up front.
- The reverse-engineering example now prints paths with `/` on every platform,
  so it rebuilds byte-for-byte on Windows too. The full test suite passes on
  Windows 11.

## 1.0.0 — 2026-11-25

First release.

- `SKILL.md` with three modes (light, investigative, rigorous), ten rules, nine
  epistemic statuses and the investigation workflow.
- Ten reference documents loaded on demand, and a machine-readable authority
  matrix (37 authorities, 23 claim types) with per-investigation extensions.
- JSON Schemas (Draft 2020-12) for the ledger and its seven record types.
- Twelve standard-library Python scripts plus a shared library: create, record, update, validate,
  evaluate and report; the final state is computed, never declared.
- Four examples generated by real runs (software, reverse engineering,
  mathematics, data analysis), rebuilt byte-for-byte by the tests.
- Seven eval cases with expected outcomes and a deterministic grader; the
  comparison with and without the skill has not been run yet.
- Test suite: scripts, rules, final states, invalidation, reports, examples,
  grader. Passes on Python 3.9, 3.11, 3.12 and 3.13 (Linux).
